# Guns 3D Models

Procedural Three.js reconstructions generated from the reference images in `guns image models/` using the img2threejs quality-gated workflow.

## Current model

| Reference | Procedural package | Subject |
|---|---|---|
| `../guns image models/01-melee.png` | `01-melee-karambit/` | Ruby-and-ivory curved karambit with real blade holes, serrations, panel seams, brass hardware, medallion, and finger ring |

Each package should contain its factory source, evidence-linked sculpt specification, reference assessment, and a README that records observed versus inferred features. Models must remain code-only and must not silently import meshes or download runtime art packs.
